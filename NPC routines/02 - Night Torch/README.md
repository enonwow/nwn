# Night Torch

A guard equips a torch at night and puts it away during the day.

## Main features

- Day/night equipment changes.
- A real equipped torch provides light.
- Combat can interrupt normal duties.

## Demo files

- Module: [DEMO-NPC-02-Night-Torch.mod](DEMO-NPC-02-Night-Torch.mod)
- Required HAK: None; this demo uses game resources.
- Routine script: `rt_torch`. Its formatted NWScript source and compiled code are embedded in the MOD; remaining scripts are event/control adapters.

## Try it

Install the files as described in the [collection README](../README.md#installation), then start a new game in this demo.

Use TEST to switch between day and night. Watch the guard equip a torch at night and put it away at dawn. You can also attack the guard to test combat interruption.

Use INSTRUCTIONS to repeat the in-game help and STATUS to inspect progress. Allow time for approach and action animations.
