# Shopping Citizen

A customer visits a merchant, exchanges bargaining lines, and returns home.

## Main features

- Confirmed approach and mutual facing.
- Ordered dialogue keeps both participants together until the reply ends.
- A supporting merchant remains available for repeated visits.

## Demo files

- Module: [DEMO-NPC-10-Shopping-Citizen.mod](DEMO-NPC-10-Shopping-Citizen.mod)
- Required HAK: None; this demo uses game resources.
- Routine script: `rt_shopping`. Its formatted NWScript source and compiled code are embedded in the MOD; remaining scripts are event/control adapters.

## Try it

Install the files as described in the [collection README](../README.md#installation), then start a new game in this demo.

Watch the customer approach the merchant, bargain and return home. The supporting merchant stays available. Use TEST to restart the visit.

Use INSTRUCTIONS to repeat the in-game help and STATUS to inspect progress. Allow time for approach and action animations.
