# Patrol Duties

A guard follows a three-stop patrol with pauses and inspection gestures.

## Main features

- Ordered waypoint traversal.
- Different observation animations at patrol stops.
- The route repeats and can be restarted.

## Demo files

- Module: [DEMO-NPC-04-Patrol-Duties.mod](DEMO-NPC-04-Patrol-Duties.mod)
- Required HAK: None; this demo uses game resources.
- Routine script: `rt_patrol`. Its formatted NWScript source and compiled code are embedded in the MOD; remaining scripts are event/control adapters.

## Try it

Install the files as described in the [collection README](../README.md#installation), then start a new game in this demo.

Watch the three patrol stops, pauses and inspection animations. Use TEST to restart the route.

Use INSTRUCTIONS to repeat the in-game help and STATUS to inspect progress. Allow time for approach and action animations.
