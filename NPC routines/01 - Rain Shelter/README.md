# Rain Shelter

Residents seek available shelter when it rains and return to their patrol when the weather clears.

## Main features

- Three residents compete for two reserved shelter spots.
- Shelter occupancy and arrival are checked before waiting.
- Normal movement resumes after the rain.

## Demo files

- Module: [DEMO-NPC-01-Rain-Shelter.mod](DEMO-NPC-01-Rain-Shelter.mod)
- Required HAK: None; this demo uses game resources.
- Routine script: `rt_shelter`. Its formatted NWScript source and compiled code are embedded in the MOD; remaining scripts are event/control adapters.

## Try it

Install the files as described in the [collection README](../README.md#installation), then start a new game in this demo.

Use TEST to toggle rain. Three residents compete for two shelter spots. They resume their patrol when the weather clears.

Use INSTRUCTIONS to repeat the in-game help and STATUS to inspect progress. Allow time for approach and action animations.
